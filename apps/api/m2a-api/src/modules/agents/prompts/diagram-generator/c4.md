# C4 Diagram — Generation Prompt

Generate a Mermaid C4 context diagram based on the structured context provided.

## Syntax rules

- Use the `C4Context` diagram type
- Declare the title using `title`
- Use `Person(id, label, description)` for human actors
- Use `System(id, label, description)` for the main system being discussed
- Use `System_Ext(id, label, description)` for external systems
- Use `Rel(from, to, label)` for relationships
- Use `UpdateRelStyle` only if directionality needs to be explicit

## Structure rules

- Place the main system at the center
- Surround it with actors (left) and external systems (right)
- Relationships must reflect the interactions in the context
- Descriptions must be short — one sentence maximum
- Do not go deeper than the Context level unless the meeting explicitly discussed containers or components

## Example of expected output

C4Context
    title System Context — M2A Platform

    Person(user, "Engineer", "Uses M2A to generate architecture docs")
    System(m2a, "M2A Platform", "Transforms meeting transcripts into architecture diagrams")
    System_Ext(github, "GitHub", "Source of code context via pull requests")
    System_Ext(gemini, "Gemini API", "LLM used for transcript analysis and diagram generation")

    Rel(user, m2a, "Uploads transcripts and views diagrams")
    Rel(m2a, github, "Fetches code context")
    Rel(m2a, gemini, "Sends prompts and receives structured output")
